# LocalSpot AI

![LocalSpot banner](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

Browser-local OpenRouter search and local discovery UI.

## Run locally

**Prerequisite:** Node.js

```bash
npm install
npm run dev
```

No deployment environment variable or app-owned AI credential is required. Open **AI Setup** in the app, save your own OpenRouter API key in browser local storage, and explicitly select a model from the live catalog (or enter an exact model ID manually).

## Checks

```bash
npm test
npm run build
```
